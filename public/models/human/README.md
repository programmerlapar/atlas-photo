# Face model assets

These model manifests and weights are distributed with `@vladmandic/human` 3.3.6 and used for local face detection and description only. No model files or photo data are fetched from a remote service at runtime.

- Human library source and MIT license: https://github.com/vladmandic/human
- Model credits and source licenses: https://github.com/vladmandic/human/wiki/Models

The included model files are `blazeface` (face detection) and `faceres` (face description/embedding). Other Human analysis modules are disabled.
