1. **By Category:** Look in the category folder (e.g., `nextjs/`, `amplify/`)
2. **By Tech Stack:** Search for `tech_stack` field in bug files
3. **By Error Code:** Search for `error_code` field
4. **By Status:** Use the status column in this index
5. **By Context:** Search for `context` field (e.g., "nextjs/app-router")
6. **By Tags:** Search for `tags` field
7. **By Related Files:** Search for `related_files` field

## Bug Report Structure

Each bug report follows this structure:

```
Docs/Bug_Reports/
├── [category]/
│   └── [descriptive-filename].md
├── INDEX.md (this file)
└── TEMPLATE.md
```

**Naming Convention (CRITICAL - AI-Friendly):**

- **File Format:** `[descriptive-title].md` (lowercase, kebab-case, descriptive)
- **Examples:**
  - `tailwind-css-variable-mapping-error.md`
  - `postcss-config-syntax-error.md`
  - `yarn-pnp-amplify-compatibility.md`
  - `typescript-path-alias-resolution.md`
- **Bug ID Format:** `BUG-XXX` (for metadata only, zero-padded number)
- **Purpose:** Descriptive filenames allow AI to understand the bug context without opening the file
- **Requirements:**
  - Use kebab-case (lowercase with hyphens)
  - Be descriptive and specific (include technology, error type, or context)
  - Include error type if applicable (e.g., `-error`, `-issue`, `-bug`)
  - Keep it concise but informative (3-6 words typically)
  - Examples: `nextjs-server-component-hydration-error.md`, `amplify-auth-token-expiration.md`

## How to Add a New Bug Report

1. **Determine Category:** Choose the most appropriate category folder
2. **Get Next Bug ID:** Check the INDEX.md for the highest bug ID, increment by 1
3. **Create Descriptive Filename:**
   - Create a descriptive, kebab-case filename based on the bug context
   - Format: `[technology]-[error-type]-[context].md` or `[error-type]-[context].md`
   - Examples: `tailwind-css-variable-mapping-error.md`, `nextjs-hydration-mismatch.md`
4. **Create File:** Copy `TEMPLATE.md` to `[category]/[descriptive-filename].md`
5. **Fill Metadata:** Complete all metadata fields in the YAML frontmatter (including bug_id: BUG-XXX)
6. **Fill Details:** Complete all sections of the bug report
7. **Update Index:** Add the bug to the appropriate section in `INDEX.md` with descriptive filename
8. **Link to Related:** Add cross-references to related bugs if applicable
